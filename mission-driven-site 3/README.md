# Mission Driven

GitHub Pages-ready static website reconstructed from the supplied Mission Driven HTML files and reference screenshots.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `portfolio.html` — Portfolio
- `volunteer.html` — Volunteer
- `styles.css` — the single shared site stylesheet

## Deploy to GitHub Pages
Upload the contents of this folder to the root of a GitHub repository, then enable **Settings → Pages → Deploy from a branch** and choose the branch containing these files.

No npm, framework, Tailwind runtime, or build step is required. The Tailwind utility rules used by the supplied designs have been compiled into `styles.css` so all four pages share one local CSS file. Google Fonts, Material Symbols, and the original supplied image URLs remain external assets.
