# Mission Driven

Static, GitHub Pages-ready website built from the supplied page designs.

## Files

- `index.html` — Home
- `about.html` — About Us
- `portfolio.html` — Portfolio
- `volunteer.html` — Volunteer
- `styles.css` — Shared styles for every page
- `DESIGN.md` — Original design-system reference

## Publish on GitHub Pages

1. Upload all files in this folder to the root of a GitHub repository.
2. Commit and push to the default branch.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the default branch and `/ (root)`, then save.

No build step, package manager, or framework is required.

## Notes

The supplied image URLs are kept as remote image sources. The site therefore needs an internet connection to load those images and the Google Fonts used by the design.
